# Employee Management & Monitoring System (Linux + Bash)

This is a simple Bash-based system that manages employee accounts and monitors system performance. Built as a practice project for Linux Admin and Bash scripting skills.

## Features:
- Add/Update/Delete employees (user accounts)
- Store employee data in CSV
- Monitor CPU, RAM, and Disk
- Create automatic backups
- Logs for all actions
- Scheduled with cron

## How to Use:
1. Run `setup.sh` to prepare the environment.
2. Use `menu.sh` to interact with the system.
3. Check `logs/` and `backup/` folders for activity.
